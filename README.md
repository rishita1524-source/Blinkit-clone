# Blinkit Homepage Clone

A responsive frontend recreation of the Blinkit homepage, developed using **HTML5 and CSS3** to practise core web development concepts and frontend layout techniques.

**Live Demo:** https://blinkitclone-ppz6.vercel.app/

**Source Code:** https://github.com/rishita1524-source/blinkitclone

---

## Overview

The Blinkit Homepage Clone is a frontend development project focused on recreating the visual layout and design of Blinkit's homepage.

The project was developed to gain practical experience in HTML structuring, CSS styling, layout management, and responsive web design while strengthening fundamental frontend development skills.

## Technologies & Tools

| Technology | Purpose |
|---|---|
| HTML5 | Structuring webpage content |
| CSS3 | Styling and layout design |
| Flexbox | Element alignment and layout management |
| CSS Media Queries | Responsive design |
| Git & GitHub | Version control and source code management |
| Vercel | Deployment and hosting |

## Key Features

- Blinkit-inspired homepage interface.
- Structured content and product sections.
- CSS-based layouts and element alignment.
- Flexbox for organizing webpage components.
- Responsive styling for different screen sizes.
- Separate stylesheets for main styling and responsive layouts.

## Getting Started

Follow these steps to run the project locally.

**1. Clone the repository**

```bash
git clone https://github.com/rishita1524-source/blinkitclone
```

**2. Navigate to the project directory**

```bash
cd blinkitclone
```

**3. Run the project**

Open `index.html` in your browser or use the Live Server extension in VS Code.

## Deployment

The project is deployed on **Vercel**.
